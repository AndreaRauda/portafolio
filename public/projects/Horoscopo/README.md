
# Horóscopo

## Descripción
Proyecto web desarrollado con HTML y CSS que presenta información sobre los doce signos del zodiaco. Permite explorar los signos y conocer sus características mediante diferentes páginas temáticas.

## Tecnologías utilizadas
- HTML5
- CSS3
- Imágenes en formato JPG, WEBP y AVIF.

## Características
- Página principal dedicada al horóscopo.
- Información organizada por los cuatro elementos: agua, aire, fuego y tierra.
- Páginas individuales para explorar los signos zodiacales.
- Diseño visual con imágenes y estilos personalizados.

## Estructura del proyecto
- `proyecto.html`: página principal.
- `signos de agua.html`: signos del elemento agua.
- `signos de aire.html`: signos del elemento aire.
- `signos de fuego.html`: signos del elemento fuego.
- `signos de tierra.html`: signos del elemento tierra.
- Archivos CSS: estilos visuales de cada sección.
- Imágenes: recursos gráficos de los signos zodiacales.

## Ejecución
Abre el archivo `proyecto.html` en un navegador web.

## Nota
Proyecto académico desarrollado para practicar la creación y organización de páginas web utilizando HTML y CSS.
