
# Regresión Lineal: Horas de Estudio y Score

## Descripción
Proyecto académico de aprendizaje automático desarrollado en Python que utiliza un modelo de regresión lineal para analizar la relación entre las horas de estudio y un puntaje (score).

## Tecnologías utilizadas
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Funcionamiento
1. Crea una base de datos de ejemplo con horas de estudio y puntuaciones.
2. Organiza y analiza los datos.
3. Entrena un modelo de regresión lineal.
4. Evalúa el modelo mediante las métricas R² y MSE.
5. Permite ingresar horas de estudio para obtener una predicción.
6. Genera una gráfica con los datos, la línea de regresión y la predicción.

## Ejecución
Instala las dependencias:

```bash
pip install -r requirements.txt
```

Ejecuta el programa:

```bash
python regresion.py
```

## Nota
Los datos utilizados son ejemplos incluidos directamente en el código y tienen fines académicos y demostrativos.
